## 解决什么问题

刚脱离高考跑道的大学生，普遍陷入三种迷失：

| 痛点 | UCompass 的解法 |
|---|---|
| 目标模糊——"除了学习不知道该干嘛" | **定锚**：聊天式引导，收敛为 ≤3 个 SMART 目标 |
| 无从下手——任务宏大，越想越拖 | **航行**：拆到"15 分钟内可启动"的周计划 |
| 计划失守——偏了没人管，慢慢弃了 | **校准**：打卡判卷 + 偏离诊断 + 自动重排 |

待办清单和课表 App 只管"记录"，UCompass 管的是**闭环**——一个会追问、会判卷、会纠偏的对话式智能体。

## 三阶段闭环

### 🧭 定锚 —— 把迷茫变成目标

- 学期时间轴当面确认，禁止静默默认
- 聊天式现状盘点：生活节奏 → 课余可支配时间估算
- 观念校准 + 四问引导（愿望 / 价值 / 障碍 / 证据）
- SMART 收敛 ≤3 个目标；组合体检：周预算合计 ≤ 课余时间 × 80%
- 产出**目标卡**：量化指标、验收证据、周时间预算

### ⛵ 航行 —— 把目标拆成计划

- 从期末验收线**倒排里程碑**（每目标 2~4 个，叠加考试周与 DDL）
- 课表智能融合：Excel / CSV / 口述三通道，排程冲突自动避让
- 周计划三段式生成：脚本查空档 → 智能体决策 → 校验器把关
- 首周轻载 60~70%；考试周、长假自动降载
- 劳逸显式排程：篮球、社团、朋友局像任务一样排入计划

### 🔧 校准 —— 让计划跟得上变化

- **一句话打卡**："今天蓝桥杯搞定 1 题" → 自动匹配任务、提取量、记账判卷
- **双指标判卷**：达成 / 部分 / 失约；差额自动滚动补载，封顶防过载
- **对账闸门**：无打卡记录不判失约，绝不冤枉学生
- **三级偏离诊断**：🟢 轻则微调 / 🟡 中则重排 / 🔴 重则回炉对话；连续重度过偏触发目标休眠——"绕行，不是弃船"
- 周结算 → 月度总结 → 学期归档，日/周/月/年四级日志全程沉淀

## 技术架构

```
你的司南UCompass/
├── SKILL.md                    # 技能主控：三阶段流程与全局规则
├── scripts/
│   ├── compass_store.py        # 航海日志引擎（11 个子命令，纯标准库零依赖）
│   └── timetable_parse.py      # Excel/CSV 课表解析器
├── references/                 # 方法论文档 ×5（定锚/航行/校准/模板/接口契约）
├── assets/compass-dashboard/   # 仪表盘模板（render 生成单文件 dashboard.html）
├── demo-data/                  # 完整学期演示数据（双击 dashboard.html 即可体验）
└── Skill评审报告.md            # 12 维度 35 子项评审报告
```

**工程设计要点**

- **本地数据优先**：全部数据存于本地 `ucompass-data/`，原子写入 + 自动备份，不经任何外部服务
- **上下文效率**：智能体禁读数据原文、只读命令摘要——数据量再大，对话成本恒定
- **人机分工**：读写 / 结算 / 校验锁定脚本（确定性），引导 / 鼓励 / 叙事交给 LLM（灵活性）
- **防误伤设计**：对账闸门、归档防覆盖、误删防护，生成物永远可安全重建

## 快速开始

UCompass 是 TeleAgent（星辰超级智能体）技能——安装启用后，对话即可触发：

| 你说 | 司南进入 |
|---|---|
| "我有点迷茫，这学期不知道怎么过" | 🧭 定锚 |
| "帮我拆解目标 / 这周怎么安排" | ⛵ 航行 |
| "今天打卡：高数错题重做了 5 道" | 记账判卷 |
| "复盘本周 / 总结一下这个月" | 🔧 校准 |
| "打开仪表盘 / 看看我的进度" | 📊 罗盘仪表盘 |

离线体验（无需 TeleAgent）：

```bash
# 直接双击 demo-data/dashboard.html 查看完整学期演示成果
python scripts/compass_store.py demo-init    # 或一键生成新的演示学期
python scripts/compass_store.py render       # 生成 dashboard.html
```
